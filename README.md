# eNDS — website

Static pages for [eNDS](https://github.com/mattiaa95/eNDS), a DS emulator
for iPhone and iPad built on melonDS: landing page, privacy policy
and terms of use.

No dependencies, no external fonts, no analytics, no third-party scripts.
Everything the pages load comes from this folder.

- `index.html` — landing
- `privacy.html` — privacy policy (the app collects no data)
- `terms.html` — terms of use
- `404.html` — not-found page
- `assets/` — stylesheet, icon and screenshots (homebrew gameplay only)

The app itself is open source under GPLv3: see the
[eNDS repository](https://github.com/mattiaa95/eNDS).

Both the app and these pages were written with heavy use of AI coding
assistants. That is stated on the landing page too, and in the app's
repository, rather than left to be inferred.

manufacturer, nor with the melonDS team.
