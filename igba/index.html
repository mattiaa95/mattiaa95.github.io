The iGBA community is on Discord

One person builds iGBA. The community is where the rest happens: help with a game that misbehaves, features being argued over before they are built, and early access to what is coming next.

Join the Discord server

  • Get help fastA game that will not boot, a save you cannot import, a controller that will not map.
  • Shape the appFeature requests are read, argued over, and some of them ship.
  • Test firstTestFlight builds land there before they reach the App Store.
  • Report bugs properlyWith a device, an iOS version and a game — the three things that make a bug fixable.

One house rule. No ROMs, no BIOS files, no links to sites that host them — not in the server, not in DMs. Bring your own games, as you already do in the app. It is the only reason an emulator like this gets to exist. Breaking this is an instant ban, with no warning.

Get in touch

Bug reports, a game that misbehaves, or just a note that it worked — all of it is read. The Discord server is usually faster; email works just as well.

Ask on Discord Email support

For a bug, it helps enormously to say which device and iOS version you are on, and which game.
